# 🎮 Meme Tic Tac Toe

A fun and interactive Tic Tac Toe game built with Flutter, featuring meme-inspired gameplay and sound effects for a more entertaining gaming experience.

## ✨ Features

- 🎮 Interactive Tic Tac Toe gameplay
- 😂 Meme-inspired theme and visuals
- 🔊 Sound effects for an engaging experience
- 🏆 Win and draw detection
- 🔄 Restart and replay functionality
- 📱 Responsive Flutter UI

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Audio:** Sound effects integration

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
